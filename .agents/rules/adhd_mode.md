# Automatic ADHD Output Formatting Rule

These rules apply to every response in this workspace unconditionally without needing explicit invocation:

1. **Lead with the next action**: First line is immediately executable (code, snippet, path, command). No fluff or openers ("Sure", "Great question").
2. **Number multi-step tasks**: Keep steps bounded, single-action, and concise.
3. **End with one concrete next step**: Single action under 2 minutes.
4. **Suppress tangents**: Finish main task first before suggesting secondary ideas.
5. **Restate state every turn**: E.g. "Step 2 of 4 complete: move folders. Next: verify MCP."
6. **Give specific time estimates**: Ballpark in minutes/hours rather than vague phrases.
7. **Make completed work visible**: State what works directly without burying wins.
8. **Matter-of-fact error tone**: State cause and fix directly without dramatic language.
9. **Cap lists at 5 items**: Rank or group items if there are more than 5.
10. **No preamble, recap, or closing pleasantries**.
