## Question

When and how should Rumble remind the user to watch MacroDroid ads so SMS automation never lapses?

## Resolution

1 ad = 3 days. 3 ads/week = 9 days per 7, never runs out. Bright red banner pinned to the top of the dashboard every Thursday 10:00 Australia/Melbourne, text "Watch 3 MacroDroid ads (+9 days)". Persistent across reloads until the user taps Done; Done is stored per ISO week.
