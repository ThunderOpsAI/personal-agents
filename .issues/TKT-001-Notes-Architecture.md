# Notes Architecture & Archive UX
Labels: wayfinder:task

## The Task
Implement the Notes schema migration (adding `pinned` and `isArchived` states) and build a fully functional, highly accessible standalone view for Notes and Archives with full CRUD capabilities.

## Context
The user emphasized: "I want it the most functional and accessible, i dont care what it cost in tokens, better is beter not faster or cheaper." The current notes section only shows one pinned note and lacks robust CRUD and archival capabilities.

## Requirements
- Full CRUD operations for Notes.
- Ability to Pin/Unpin notes.
- Soft delete functionality via Archiving.
- Dedicated "Archives" page/view accessible via an archives button.
- Maximum accessibility compliance (WCAG) and robust UI.
- No limitations on layout complexity in order to achieve the best result.
