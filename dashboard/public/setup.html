Quick Visual QA Cheat Sheet (What to Check)

When inspecting source.blend in the Blender 3D Viewport (press Z → Material Preview):

👕 Roblox Layered Clothing

  • Unhide _InnerCage & _OuterCage.
  • Both cages must have exactly 1,358 vertices.
  • UV map must be named map1.
  • Rotate spine/leg bones in Pose Mode to check deformation.

👑 Roblox Rigid Accessories

  • Check for Attachment empty (e.g. HatAttachment).
  • Position must be precisely at (0.0, 0.0, 0.0).
  • Rings & halos rotated 90° on X so opening aligns with head/body.
  • PBR textures bound cleanly in Material Preview.

⚡ Fortnite UEFN Props

  • Unhide all UCX_ collision objects.
  • Each UCX hull must be convex with ≤ 256 vertices.
  • Centimeter scale: 1 Blender unit = 1 cm.
  • .verse file present in export/ for interactive props.

📄 Detailed step-by-step guide is inside: inspection/INSPECTION_GUIDE.md
📊 Record your review status in: inspection/inspection_log.csv
